# 🥗 MacroSnap

MacroSnap is an AI-powered nutrition assistant that helps users understand the food they eat.

Users can:
- 📸 Upload a photo of their meal
- 🍽️ Describe their meal using text
- 🤖 Get AI-based calorie and macro estimates
- 📊 View estimated protein, carbohydrates, and fat
- 📱 Send their meal summary to WhatsApp

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API
- Twilio WhatsApp API
